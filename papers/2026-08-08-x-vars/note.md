## 한 줄 요약

축구 심판 판정을 "설명"할 수 있는 최초의 멀티모달 LLM — 파인튜닝한 CLIP의 분류 예측을 텍스트 프롬프트로 LLM에 주입하는 학습 방식으로, 심판급 설명 품질(휴먼 스터디 3.8 vs 심판 4.0)과 판정 분류 SOTA(+19%)를 동시에 달성.

## 핵심 기여

1. **SoccerNet-XFoul 데이터셋** — 10k 비디오 클립, 22k+ VQA 트리플렛을 70여 명의 현직 심판(평균 655경기 주심 경력)이 직접 주석. 스포츠 도메인 최대 규모의 "판정 + 이유 설명" 데이터셋.
2. **X-VARS 모델** — Video-ChatGPT 기반 VLM. 파인튜닝한 CLIP ViT-L/14의 멀티태스크 분류 예측(파울 유형, 심각도)을 텍스트로 LLM 입력에 주입하는 새로운 학습 패러다임.
3. **철저한 평가** — 20명 심판 블라인드 휴먼 스터디, 텍스트 예측 주입의 효과 ablation, 비디오 토큰 활용 여부 검증.

## 한줄평

"분류기 예측을 프롬프트에 넣어주면 LLM 설명이 좋아진다"는 단순하지만 실용적인 아이디어를, 진짜 심판 70명을 동원한 데이터셋으로 증명한 성실한 논문. 다만 평가가 4개 질문 중 2개에 집중되고 희귀 파울에 약한 건 한계.

# 정독 리뷰

## 문제 정의

- AI 모델 성능이 올라갈수록 설명가능성·투명성은 떨어지는 트레이드오프가 있음. 심판 판정처럼 **주관적이고 이해관계가 큰 결정**(클럽 재정에 직결)에는 "왜"를 설명하는 능력이 신뢰의 전제 조건.
- 축구 심판 판정은 규칙(Laws of the Game) 이해 + 맥락(의도, 위치, 강도, 경기 흐름) + 미래 예측(유리한 진행이었나?)까지 요구되는, 설명가능성 연구의 이상적인 테스트베드.
- 선행 사례: 2022 카타르 월드컵의 반자동 오프사이드 판독 — 3D 시각화로 "보여주는" 설명. 이 논문은 언어로 설명하는 쪽.

## 선행 연구 대비

- **VARS (Held et al., CVPRW 2023)**: 같은 저자들의 전작. SoccerNet-MVFoul로 멀티뷰 파울 분류만 수행 — 판정은 하지만 설명은 못 함. X-VARS는 이걸 VQA로 확장.
- **기존 XAI 기법** (LIME, SHAP, Grad-CAM, counterfactual): 피처 중요도/히트맵 수준의 설명. 이 논문은 "자연어 대화형 설명"(Explanation via Language) 노선.
- **기존 스포츠 VQA 데이터셋** (GOAL 1k, Sports-QA 6k): 규모도 작고 단순 질문. SoccerNet-XFoul은 판정 이유 설명 + 맥락 의존 + 미래 예측이 필요한 유일한 데이터셋.

## 방법

![아키텍처](assets/fig3-architecture.png)

**아키텍처** (Video-ChatGPT 백본 + 수정):
- 비디오(16프레임, 파울 전후 8프레임씩, 224p) → **파인튜닝된 CLIP ViT-L/14** → 프레임 피처 + 히든 스테이트
- 히든 스테이트를 시간축/공간축으로 각각 평균 풀링 후 concat → 시공간 피처 z → **선형 프로젝션** → 비주얼 토큰 w
- 프레임 피처는 2개 분류 헤드로: **C_foul** (파울 유형 8종: Tackling, Holding, Pushing 등) / **C_sev** (No offence / Offence+No card / +Yellow / +Red)
- 프롬프트 구성: `USER: <질문> <P_foul> <P_sev> <비주얼 토큰 w>` → **Vicuna-v1.1** (LLaVA 가중치 초기화)이 답변 생성
- 핵심 아이디어: **분류기의 argmax 예측을 텍스트로 프롬프트에 주입** → LLM이 분류 지식을 활용해 설명 품질 향상

**2단계 학습**:
1. **Stage 1 — 축구 지식 주입**: CLIP + 분류 헤드를 SoccerNet-MVFoul에서 멀티태스크(두 CE loss 합산) 파인튜닝. 범용 CLIP은 축구 클립끼리 피처가 비슷해서 LLM이 구분 못 하는 문제를 해결. (14 epochs, lr 5e-6, V100 1장, ~9시간)
2. **Stage 2 — 피처 정렬 + 엔드투엔드**: CLIP 동결, 프로젝션 레이어 + LLM 레이어 1%만 QLoRA로 파인튜닝. 학습 시엔 CLIP 예측 대신 **ground truth**를 주입(노이즈 방지). (3 epochs, lr 2e-4, A100 40GB 2장, ~2시간)

## 실험

**분류 성능** (SoccerNet-MVFoul, single-view):

| 모델 | 파울유형 Acc | Offence/Severity Acc |
|------|------------|---------------------|
| VARS-MViT (전 SOTA, multi-view) | 0.45 | 0.43 |
| 파인튜닝 CLIP-L/14 (single-view) | **0.51** | 0.52 |
| X-VARS | / | **0.62** |

- 멀티뷰 없이 싱글뷰만으로 전 SOTA 대비 offence/severity **+19%p**.
- X-VARS의 분류 성능은 생성된 설명에서 ChatGPT-3.5로 레이블을 추출해 측정.

**휴먼 스터디** (심판 20명, 블라인드, 5점 척도):

| | 평균 | 4~5점 비율 |
|---|------|-----------|
| 인간 심판 설명 | 4.0 | 79% |
| X-VARS 설명 | 3.8 | 76% |

- 46%의 클립에서 X-VARS 설명이 인간 심판보다 높은 점수.
- disagree가 몰린 클립은 데이터셋에서 희귀한 파울(팔꿈치, 밀기)이었음.

**Ablation**:
- **비디오 토큰을 실제로 보나?** — X-VARS 최종 답변이 입력된 CLIP 예측과 76%만 일치 → 예측을 그대로 받아쓰지 않고 비디오 토큰으로 재평가함.
- **텍스트 예측 주입 효과** — 주입 없는 버전은 "No foul"을 한 건도 못 맞추고 balanced acc 29%. 주입 버전이 +6%p, 특히 희귀 액션에서 GT에 더 가까운 설명.
- 사용자가 유도 질문("레드카드 줘야 하지 않아?")을 해도 판정을 유지하는 경향 — LLM 특유의 아첨(sycophancy)이 억제됨.

## 한계

- **저자 인정**: 환각(영상에 없는 동작을 언급) 존재. 설명에서 파울 유형을 명시하지 않아 유형 분류 정확도는 측정 불가.
- **내가 보기에**:
  - 4개 질문으로 데이터를 만들었지만 평가는 2개 질문(파울 여부, 카드)에만 집중 — 미래 예측형 질문(promising attack, advantage)의 성능은 미검증.
  - GT 자체가 주관적(같은 장면에 심판마다 다른 답, 평균 1.5개 답변) — "정답과 일치"라는 평가 프레임이 흔들림. 휴먼 스터디로 보완했지만 20명×20클립은 표본이 작음.
  - 백본이 Vicuna-v1.1 + Video-ChatGPT (2023년 기준) — 지금 기준으로는 구세대. 방법론의 기여와 모델 성능의 기여가 섞여 있음.
  - 번역 파이프라인(4개 언어 → ChatGPT 번역 → 심판 검수)에서 뉘앙스 손실 가능성.

- 핵심 통찰은 "**전문 분류기의 예측을 텍스트로 프롬프트에 주입**"이 저비용(선형 레이어 + LLM 1% QLoRA)으로 도메인 특화 설명 능력을 끌어낸다는 것. 요즘 식으로 보면 tool-use/구조화된 컨텍스트 주입의 원형.
- 데이터셋 설계가 배울 점: 주관적 태스크에서 정답을 하나로 강제하지 않고 **복수 답변(1.5개/질문)을 그대로 학습** — "타당한 해석의 범위"를 배우게 함. 법령 해석, 심사 자동화 같은 주관적 도메인에 그대로 이식 가능한 아이디어.
- 평가 방법도 참고할 만: 생성 텍스트 평가에 언어 메트릭 대신 블라인드 휴먼 스터디 + "생성문에서 ChatGPT로 레이블 추출해 분류 정확도 측정" 조합.
