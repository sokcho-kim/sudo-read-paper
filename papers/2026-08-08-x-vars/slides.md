# 1.1 문제의식: 성능과 설명가능성의 트레이드오프

- 모델 성능이 올라갈수록 판단 근거는 수백만 개 가중치에 분산되어 읽을 수 없게 됩니다
- 의료·자율주행·스포츠처럼 **신뢰가 전제인 도메인**에서는 치명적입니다
  - 축구에서 판정은 클럽의 재정과 존폐에 직결 → 설명 능력이 수용의 전제 조건
- 선례: 2022 카타르 월드컵 반자동 오프사이드 — 3D 재현으로 **"보여주는"** 설명
- 이 논문의 접근: 같은 문제를 **"언어로 설명하는"** 방향으로

> 출발점: 설명을 후처리로 붙이지 말고, **학습 목표 자체로** 만들자

# 1.2 왜 축구 심판인가 · 1.3 기여

**왜 축구 심판 판정인가**
- 규칙(Laws of the Game) + 맥락(의도·위치·강도) + **미래 예측**(어드밴티지)까지 필요한 복합 추론
- 심판마다 해석이 갈리는 **본질적으로 주관적인** 태스크 — "정답이 하나가 아닌" 상황에서의 설명 능력을 시험 가능

**기여 3가지**
1. **SoccerNet-XFoul** — 심판 70+명이 주석한 22k+ VQA 데이터셋 공개
2. **X-VARS** — 캡셔닝·QA·액션 인식·대화가 가능한 VLM, 설명 품질 인간 수준
3. **철저한 평가** — 새 학습 패러다임 분석 + 심판 대상 블라인드 휴먼 스터디

# 2. Related Work: X-VARS의 족보

**스포츠 비디오 이해**
- SoccerNet 시리즈가 표준. 직계 전작 **VARS**(CVPRW 2023, 같은 저자들) — 멀티뷰 파울 **분류만**. 판정은 하지만 설명은 못 함

**비전-언어 모델 (VLM)**
- **CLIP**(2021): 이미지·텍스트 공동 임베딩 → **LLaVA**(2023): 선형 레이어 하나로 CLIP과 LLM 연결 → **Video-ChatGPT**(2023): 비디오로 확장, **X-VARS의 백본**

**설명가능성 (XAI)**
- LIME·SHAP·Grad-CAM·counterfactual: 히트맵/피처 중요도 수준의 **사후 설명** — "어디를 봤는지"는 알려주지만 "왜 그래서 파울인지"는 말하지 못함
- 이 논문은 **자연어 대화형 설명**(Explanation via Language) 노선

# 3. 왜 데이터부터 바꿨나

블랙박스의 근본 원인 중 하나는 **데이터의 형태**입니다.

- 기존: `[영상 → 파울(1)]` — 모델은 결과만 맞추도록 최적화되고, 설명 능력은 학습 신호 어디에도 없음
- XFoul: `[영상 → "수비수가 낮은 강도로 발을 건드렸으므로 카드 없음"]`
  - 인간 심판의 **추론 과정(reasoning)을 문장으로 라벨링**
  - 모델은 이 텍스트로 '설명하는 방법'을 지도학습 (instruction tuning)

**문제는 이런 데이터가 세상에 없었다는 것** → 직접 만들었습니다

---

# 3.1 질문 설계

심판이 경기 중 마주하는 가장 근본적인 판단 4가지입니다.

| # | 질문 | 요구 능력 |
|---|---|---|
| 1 | 파울인가? 왜? | 규칙 + 맥락 (의도·위치·강도) |
| 2 | 무슨 카드? 왜? | 심각도 판단 (속도, 부상 위험) |
| 3 | 유망한 공격을 끊었나? | **미래 예측** — 파울이 없었다면? |
| 4 | 어드밴티지를 줄 수 있었나? | **미래 예측** — 프리킥보다 진행이 유리한가? |

3·4번은 **일어나지 않은 미래**를 추론해야 합니다. "공은 무슨 색인가?" 수준의 기존 VQA와는 차원이 다른 난이도입니다.

---

# 3.2 주석 과정과 규모

**주석자**
- 현직 심판 **70+명**, 3개월 캠페인 — 경력 140~2,279경기 (평균 655경기)
- 피로 방지: 원하는 만큼만, 언제든 중단 가능
- 언어 장벽 제거: 독·불·영·서 4개 언어 답변 허용
  → ChatGPT-3.5로 영어 번역 → **다른 심판이 번역 검수**

**규모 — 스포츠 도메인 최대**
- **10k 비디오 클립, 22k+ 질문-답변 쌍**, 총 540k+ 단어 (답변당 평균 25단어)
- 비교: GOAL 1k 클립, Sports-QA 6k 클립 — 그마저 단순 질문 위주
- 판정 이유 설명을 다루는 **유일한** 데이터셋

# 4. Model
## 눈 → 통역사 → 뇌

---

# 4.1 전체 구조

![h:400](assets/fig3-architecture.png)

**눈** CLIP이 영상을 피처로 · **통역사** 선형 레이어가 LLM 임베딩 공간으로 번역 · **뇌** Vicuna가 종합해 설명을 생성합니다

---

# 4.2 눈: 파인튜닝된 CLIP ViT-L/14

**입력**: 클립당 16프레임, 224p — 파울 시점 기준 **전 8 + 후 8프레임**

$$f_i,\ h_i = \mathrm{CLIP}(v), \quad v \in \mathbb{R}^{T \times H \times W \times C}$$

- 히든 스테이트 $h_i$를 두 방향으로 평균 풀링합니다:
  - 시간축 풀링 → 공간 피처 $t$ (어디서 무슨 일이) / 공간축 풀링 → 시간 피처 $s$ (언제 어떻게)
  - concat → 시공간 피처 $z = [t\ \Vert\ s]$
- **차별점**: 프레임 피처 $f_i$는 별도 풀링해 **분류 헤드 2개**로 1차 판단까지
  - $C_{foul}$: 파울 유형 8종 (Tackling, Holding, Pushing, Elbowing, Dive …)
  - $C_{sev}$: No offence / Offence+No card / +Yellow / +Red

---

# 4.3 통역사: 선형 프로젝션 레이어

- LLM은 텍스트 토큰의 임베딩 공간만 이해합니다
- 비디오 피처 $z$를 선형 레이어 하나로 그 공간에 투영합니다:

$$w = \mathrm{Linear}(z)$$

- $w$ = LLM이 읽을 수 있는 **"시각적 단어"** 시퀀스 (visual tokens)
- 선형 레이어 하나로 충분한가?
  - LLaVA·Video-ChatGPT가 이미 검증한 설계입니다
  - 게다가 **Video-ChatGPT의 사전학습된 프로젝션 가중치를 재사용** (10만 비디오-텍스트 쌍으로 학습된 것) → 밑바닥부터 학습하는 비용을 회피

---

# 4.4 뇌: Vicuna-v1.1 + 프롬프트 설계

LLM에 세 가지 정보가 동시에 들어갑니다 (논문 식 6):

```
USER: <질문> <P_foul> <P_sev> <비디오 토큰 w>
Assistant: (판정 + 이유 생성)
```

1. **질문** — 4가지 심판 질문 중 하나
2. **$P_{foul}, P_{sev}$** — 분류 헤드의 argmax 예측을 **텍스트로 주입** ← 핵심 아이디어
3. **$w$** — 번역된 영상 토큰

- LLM은 Vicuna-v1.1, **LLaVA 가중치로 초기화** — 시각 대화 능력을 물려받습니다

> 비유: 심판이 눈으로 보고($w$), 부심의 1차 의견을 듣고($P$), 입으로 이유를 설명하는 구조

# 5. Training
## 2단계 학습 전략

---

# 5.1 Stage 1: 축구 지식 주입

**문제: 범용 CLIP은 축구를 모릅니다**
- 심각도 판단에 필요한 강도·속도는 **시간적 단서** — 정지 이미지 학습으로는 안 잡힘
- 모든 입력이 축구 클립 → 범용 CLIP의 피처가 서로 너무 비슷함
- 피처가 뭉쳐 있으면 LLM이 클립 간 차이를 구분할 수 없음

**해결: CLIP + 분류 헤드를 SoccerNet-MVFoul로 파인튜닝**
- 두 태스크의 크로스엔트로피 손실 합산 (멀티태스크)
- V100 1장 · 14 epochs · lr 5e-6 · 약 9시간

→ 축구 클립들이 피처 공간에서 **의미 있게 분리**되기 시작합니다

---

# 5.2 Stage 2: 정렬 및 엔드투엔드 학습

**무엇을 학습하나**
- CLIP·분류 헤드는 **동결** — 축구 지식 보존
- 프로젝션 레이어 + **LLM 레이어의 단 1%만 QLoRA** 파인튜닝
- A100 40GB 2장 · 3 epochs · lr 2e-4 · 약 2시간

**디테일: 학습 때는 예측 대신 정답을 주입합니다**
- $P_{foul}, P_{sev}$ 자리에 ground truth $G_{foul}, G_{sev}$ — CLIP 예측의 노이즈가 학습을 오염시키는 것을 방지
- 단, GT(MVFoul)와 심판 답변(XFoul)이 항상 일치하지는 않음
  → 모델이 힌트만 맹신하지 않고 **비디오 토큰도 보도록** 자연스럽게 유도됨

**전체 비용: GPU 3장 × 반나절** — 저비용 도메인 특화 레시피

# 6.1 분류 성능: 설명하면서 판정도 더 잘한다

| 모델 | 뷰 | 파울 유형 Acc | Offence/Severity Acc |
|---|---|:---:|:---:|
| ResNet | multi | 0.32 | 0.34 |
| R(2+1)D | multi | 0.34 | 0.39 |
| VARS-MViT (전 SOTA) | multi | 0.45 | 0.43 |
| 파인튜닝 CLIP (Stage 1) | **single** | **0.51** | 0.52 |
| **X-VARS** | **single** | / | **0.62** |

- 멀티뷰 없이 **싱글뷰만으로** 전 SOTA 대비 **+19%p**
- 측정 방법: 생성된 설명에서 **ChatGPT-3.5로 레이블을 추출**해 GT와 비교
- 파울 유형은 설명에 명시되지 않는 경우가 많아 측정 불가

---

# 6.2 휴먼 스터디: 심판과의 블라인드 비교

**설계** — 심판 20명(평균 490경기), 각자 20클립, 출처(인간/AI)를 모른 채 5점 척도 평가

| | 평균 | 1점 | 2점 | 3점 | 4점 | 5점 |
|---|:---:|:---:|:---:|:---:|:---:|:---:|
| 인간 심판 | **4.0** | 3% | 10% | 8% | 46% | 33% |
| X-VARS | **3.8** | 3% | 17% | 4% | 46% | 30% |

- **46%의 클립에서 X-VARS 설명이 인간 심판보다 높은 점수**
- 분포도 거의 동일 — 4~5점 비율 79% vs 76%
- 2점이 몰린 곳: **희귀한 파울**(팔꿈치, 밀기) → 데이터 불균형의 흔적

---

# 6.3 Ablation: 핵심 설계가 실제로 먹혔나

**Q1. LLM이 힌트를 그냥 받아쓰는 건 아닌가?**
- 최종 답변과 입력된 CLIP 예측의 일치율: **76%**
- 100%가 아니라는 것 = 힌트를 복사하지 않고 **비디오 토큰으로 재평가**한다는 증거
- 24%의 경우 "분류기가 틀렸다"고 판단하고 뒤집습니다

**Q2. 텍스트 예측 주입이 없다면?**
- 주입 없는 버전: "No foul"을 **한 건도 못 맞춤**, balanced acc 29%
- 주입 버전이 +6%p, 특히 희귀 액션에서 GT에 가까운 설명
- → 분류기 힌트가 **데이터 불균형의 완충재** 역할

# 7.1 한계: 블랙박스는 절반만 열렸다

**저자 인정**
- **환각** — 영상에 없는 동작을 언급하는 경우 존재
- 설명이 생성됐다고 항상 참인 건 아님 — "그럴듯한 설명" ≠ "실제 판단 근거" (사후 합리화 가능성)

**추가로 짚을 것**
- 평가가 4개 질문 중 2개에 집중 — 미래 예측형 질문은 미검증
- GT 자체가 주관적인데 "정답 일치" 프레임으로 평가 / 휴먼 스터디 표본 작음 (20명)
- 백본이 Vicuna-v1.1(2023) — 방법론 기여와 백본 성능 기여가 섞임

**그래도** — 결과만 뱉던 모델 → 심판이 4점 줄 만한 설명을 생성하고, 설명을 **평가 가능한 대상**으로 만들었습니다

---

# 7.2 생각해볼 질문들

1. X-VARS의 설명은 **판단의 근거**일까요, 판단 후에 만들어낸 **그럴듯한 사후 합리화**일까요? 이 둘을 실험으로 구분할 수 있을까요?
2. 질문당 1.5개의 **복수 정답 학습** — 법령 해석, 심사, 의료 소견처럼 주관적 판단이 필요한 다른 도메인에 이식한다면?
3. 백본을 최신 MLLM으로 바꾸면 환각은 사라질까요, 아니면 **더 그럴듯한 환각**이 될까요?
4. "분류기 예측을 텍스트로 주입"은 지금 관점에서 보면 tool-use/구조화된 컨텍스트 주입의 원형 — 어디까지 일반화될까요?
